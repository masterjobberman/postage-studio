# Security

## Supported version

Security fixes target the latest release. Use an up-to-date Windows installation and current releases of this application.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting option on the repository Security tab when available. Do not put exploit details, personal labels, credentials or customer information in public issues. If private reporting is unavailable, open a minimal issue asking for a private reporting channel without disclosing the vulnerability.

## Scope and precautions

The app handles documents locally. It has no service, login system, telemetry or upload feature. Printing follows the selected Windows printer and its driver. Documents are parsed by third-party PDF and image libraries; local processing does not make malicious files harmless. Only open documents from sources you trust.

Published releases are unsigned unless explicitly stated otherwise. Checksums help detect changed downloads but do not certify safety. Tests and dependency checks reduce risk; they are not a comprehensive security audit.
