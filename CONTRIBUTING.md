# Contributing

Describe the expected and actual behaviour, Windows version, app version and input format. Use a synthetic label to reproduce the issue. Never submit real names, addresses, tracking numbers, barcodes from live labels, credentials or personal file paths.

Keep processing local. Test changes with `python verify_sizes.py` on Windows and manually inspect the preview. Printing changes should include the selected dimensions and the printer-driver behaviour; distinguish virtual-PDF tests from physical printing.

Contributions are made under this project's AGPL v3 licence. Do not submit proprietary carrier assets or documents you cannot redistribute.
